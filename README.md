# Louis Vuitton Website Recreation

An independent fashion website recreation inspired by Louis Vuitton.

## About the Project

This project is a front-end website recreation created for educational and portfolio purposes. It focuses on recreating the visual experience of a luxury fashion website.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Remix Icon
- Swiper.js

## Features

- Fashion-inspired website layout
- Product and category sections
- Image-based product displays
- Interactive website elements
